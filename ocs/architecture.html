1. Overview — Dual Mode

REX (Runtime Execution Layer) runs in two modes from the same installation:

ModeUse CaseEntry Point
Vibe Coding Human ↔ Agent (like Codex/Claude Code) runtime CLI — interactive REPL
Tool Provider RONI/orchestrator → Agent (programmatic) REX Python API — await rex.run_agent(...)

Mount Resolution (No Globs)

# Resolved at container start to ABSOLUTE paths
read_write_mounts:
  - source: ".worktrees/{agent_id}"         → /workspace (RW)
  - source: ".runtime/sessions/{sid}/agents/{aid}" → /workspace/.runtime/sessions (RW)

read_only_overlays:
  - source: ".git"                          → /workspace/main/.git (RO)
  - source: ".github/workflows"             → /workspace/main/.github/workflows (RO)

# Secrets NEVER mounted - env vars only

sequenceDiagram participant Agent as AgentLoop participant Executor as ToolExecutor participant Policy as PermissionPolicy participant Sandbox as Docker Guard Agent->>Executor: execute(tool, args) Executor->>Policy: check(tool, operation, args) alt ALLOW Policy-->>Executor: ALLOW Executor->>Sandbox: JSON-RPC call Sandbox-->>Executor: ToolResult Executor-->>Agent: ToolResult else DENY Policy-->>Executor: DENY + reason Executor-->>Agent: ToolResult(success=false, error) else ASK Policy-->>Executor: ASK + reason Executor-->>Hook: PERMISSION_ASK event Hook-->>RONI/Human: Callback with details alt Human/RONI allows Executor->>Sandbox: JSON-RPC call else Denied Executor-->>Agent: ToolResult(success=false) end end

8. Configuration

Project Config (`.runtime/config.yaml`)

project:
  name: "my-project"
  root: "/home/user/my-project"

roles:
  CODER:
    model: "gemini/gemini-flash"
    max_steps: 25
    allowed_tools: ["fileops", "bash", "git", "websearch"]
    sandbox:
      network: "bridge"
      memory: "2G"

task_spawn:
  max_depth: 3
  max_concurrent: 5
  max_total_per_session: 20

litellm_rate_limit:
  redis_url: "redis://localhost:6379/0"
  requests_per_minute: 60
  tokens_per_minute: 100000
  max_concurrent: 3

session:
  history_file: ".runtime/sessions/{session_id}/history.jsonl"
  checkpoint_interval: 10

9. Acceptance Tests (Definition of Done)

TestDescriptionPass Criteria
T1: Python Project Start in Python project, fix bug, add test, run pytest Bug fixed, tests pass, diff shown
T2: Java Project Start in Java project, make change, run Maven/Gradle Change applied, tests pass
T3: Model Switch Same task with `gemini/gemini-flash` vs `nvidia/nemotron-ultra` Works without code changes
T4: Session Recovery Interrupt task, restart runtime, resume State restored, continues
T5: Security Attempt `bash:rm -rf /` or `git:push` without permission Blocked or ASK triggered
