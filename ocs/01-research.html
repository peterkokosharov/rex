Research: Open Source AI Coding Agents — Сравнителен Анализ

Дата: 2026-10-31 | Цел: Определение на best practices и gap-ове за изграждане на runtime (Claude Code-like) за OpenAI-компатибилни модели през LiteLLM proxy

1. Проучени Open Source Проекти

Проектът Aider (Aider-AI/aider) — 25k+ ⭐

Python CLI Agent
  • Архитектура: Модулен дизайн с coders/ (20+ coder класове: Architect, EditBlock, UDiff, WholeFile, Patch, Search/Replace)
  • LLM интеграция: llm.py — поддържа OpenAI, Anthropic, OpenRouter, Ollama, Gemini, DeepSeek, Vertex, Bedrock, Azure
  • Repo Map: repomap.py — семантично индексиране на кодовата база (ctags + tree-sitter), контекст за LLM
  • Инструменти: Read/Write/Edit/Grep/Glob/LS/Bash — изпълнявани през shell.py с permission system
  • Git интеграция: Автоматични commit-и, diff preview, undo
  • Voice/Voice-to-code: voice.py — Whisper интеграция
  • Benchmark suite: benchmark/ — SWE-bench, HumanEval, custom tasks

Проектът learn-claude-code (shareAI-lab/learn-claude-code) — 79k+ ⭐

Python CLI Agent Harness
  • Философия: "Bash is all you need" — минимализен agent harness, изграден от 0
  • Структура: 17 стъпкови модула (s01_agent_loop → s17_goal_loop)
  • Ключови модули:
    • s01_agent_loop — основен ReAct loop
    • s03_permission — permission system за tools
    • s04_hooks — pre/post tool hooks
    • s06_subagent — subagent spawning
    • s07_skill_loading — dynamic skill loading
    • s08_context_compact — context compaction/summarization
    • s10_task_system — background task system
    • s13_agent_teams — multi-agent teams
    • s14_mcp_plugin — MCP integration
    • s16_workflow_runtime — workflow execution
  • Skills: skills/ — agent-builder, code-review, mcp-builder, pdf

Проектът CoreCoder (he-yufeng/CoreCoder) — 1.8k+ ⭐

Python CLI Minimal Agent (~1000 LOC)
  • Философия: "NanoGPT for coding agents" — минимализъм, чистота
  • Компоненти: agent.py, cli.py, config.py, context.py, hooks.py, llm.py, mcp.py, permissions.py, session.py, shell.py
  • Tools: В tools/ — file ops, bash, search, web
  • Checkpoints: checkpoints.py — session state persistence
  • LLM: Поддържа всякакъв LLM чрез OpenAI-компатибилен API

Проектът pydantic-deepagents (vstorm-co/pydantic-deepagents) — 1.1k+ ⭐

Python Framework PydanticAI-based
  • Философия: "Open-source, self-hosted Claude Code" на PydanticAI
  • Особености: Tool-calling, sandboxed execution, multi-agent teams, skills, checkpoints, unlimited context
  • Архитектура: agent.py, subagents.py, goal.py, spec.py, features/, bundled_skills/, mcp/
  • Деплой: install.sh, Docker, apps/ за web/desktop frontends

Проектът Nano (pnegahdar/nano) — 180 ⭐

Python Single-file
  • Философия: "One file. Under 200 lines. Zero dependencies. It's a coding agent."
  • Инструмент: Само execute_shell — всичко през shell
  • Approval: Interactive (y/a/n) + NANO_APPROVE=all за auto-mode
  • Model: OpenAI Responses API, OPENAI_MODEL env var
  • Sessions: JSON persistence в ~/.nano_sessions.json

3. Mermaid Диаграма: Feature Coverage Matrix

4. Какво НЕ има в Open Source проектите (Claude Code Extras)

🔍 Gap Analysis: Какво предлага Claude Code ВЪВНАДЛЕЗНО
  • Native Anthropic Integration: Пряк достъп до Claude модели без proxy, оптимизирани промпти, кеширане на промпти (prompt caching)
  • Semantic Code Intelligence: In-process AST parsing, symbol navigation, call graphs, refactoring tools — не само grep/ctags
  • Advanced Context Management: Автоматично сумиране на стари разговори, priority-based context retention, cross-session memory
  • Rich UI/UX: Syntax highlighting в терминал, diff rendering, progress indicators, streaming thinking blocks, markdown rendering
  • Built-in Skills Marketplace: Официален екосистем от skills, auto-update, versioning, dependency resolution
  • Enterprise Features: SSO, audit logs, policy enforcement, data residency, admin console
  • IDE Integration: VS Code, JetBrains plugins с bidirectional sync
  • Multi-modal: Image input, screenshot analysis, diagram generation
  • Custom Model Fine-tuning: Enterprise customers могат да fine-tune-ват модели за техния код
  • Managed Infrastructure: Не trzря да хостваш proxy, sandbox, monitoring — всичко е managed
⚠️ Gap: Docker Sandbox в Open Source

Само Aider и pydantic-deepagents имат Docker поддръжка. Няма стандартна "guard" архитектура като при Codex, където ВСИЧКИ инструменти (bash, file ops, network) минават през контейнер с JSON-RPC/stdio интерфейс.

⚠️ Gap: Hierarchical Agent Orchestration

learn-claude-code (s13) и pydantic-deepagents имат subagents, но нямат пълна иерархия: chat → agent → subagent → sub-subagent с message passing, shared context, wait-for-idle, delegation patterns.

⚠️ Gap: Standardized Skills Format

Всеки проект има свой формат. Няма общ стандарт за: YAML/JSON schema, hooks declaration, auto_mode, permissions, dependencies, versioning, marketplace index.

⚠️ Gap: Orchestrator-Driven Dev Workflow

Няма инструмент, който да моделира Opus→Sonnet→Haiku→Sonnet pipeline с context isolation, SKILLS.md handoff, Plan-to-HTML с Mermaid UML, human-in-the-loop approval.

Нашата уникална стойност (The "MORE")

  1. LiteLLM Proxy Native: Първокласна поддръжка за LiteLLM — model routing, fallback, cost tracking, load balancing
  2. Docker Guard Architecture: Всички инструменти през sandbox container с JSON-RPC/stdio — Codex-inspired
  3. Orchestrator Workflow Engine: Вграден engine за Opus/Sonnet/Haiku pipeline с SKILLS.md, Plan-to-HTML, Mermaid UML
  4. Standard Skills Format: Единен стандарт за skills с hooks, auto_mode, permissions, marketplace
  5. Kikolib Foundation: Zero-deps, stdlib-only, stable Linux native wrappers (OpenSSL, libsecret, systemd)
  6. Bulgarian-first UI: Цялостна локализация на кирилица, български съобщения, грешки, help
