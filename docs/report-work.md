## Technical Implementation

### Search Engines (HTML Scraping, Zero API Keys)

| Engine | Source | Parsing Method | Weight |
|--------|--------|----------------|--------|
| **Brave** | `search.brave.com/search` | `data-testid` attributes | 1.0 |
| **Bing** | `www.bing.com/search` | `li.b_algo`, `h2 a`, `b_caption`, `cite` | 0.9 |
| **DuckDuckGo** | `html.duckduckgo.com/html/` | `data-testid` / class patterns | 0.8 |

### Key Technical Fixes

| Issue | Solution |
|-------|----------|
| **BraveEngine title parsing** | Fixed regex for `<a><span>title</span></a>` structure (title inside `<span>` within `<a>`) |
| **BingEngine/DuckDuckGoEngine inheritance** | Now inherit `SearchEngine` base class for `fetch_html`, `normalize_url`, `_last_html` |
| **ResultMerger** | Added missing `import re` |
| **Circular imports** | Used `TYPE_CHECKING` guards in `orchestrator/orchestrator.py` |
| **Agent Loop Integration** | Added `("websearch", lambda: WebSearchTool())` to factories in `runtimelib/agent/loop.py` |

## Architecture

```
WebSearchTool (Tool interface)
    │
    ├── BraveEngine (primary, weight 1.0)
    ├── BingEngine (fallback, weight 0.9)
    └── DuckDuckGoEngine (fallback, weight 0.8)
            │
            └── ResultMerger (dedup by URL, rank by engine_weight * score - position_penalty)
```
